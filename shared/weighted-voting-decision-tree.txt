WEIGHTED VOTING SYSTEM - DECISION TREE
================================================================================

INPUT: votes[], taskType, options
│
├─ VALIDATION
│  │
│  ├─ votes.length === 0?
│  │  └─ YES → ERROR: "empty_votes"
│  │  └─ NO → Continue
│  │
│  └─ All same answer?
│     └─ YES → EDGE CASE: "unanimous"
│     │         └─ Fast-path: return unanimous consensus
│     └─ NO → Continue
│
├─ CONFIDENCE FILTERING
│  │
│  ├─ Filter votes by minConfidence threshold
│  │  └─ filtered.length === 0?
│  │     └─ YES → EDGE CASE: "all_votes_below_threshold"
│  │     │         └─ Action: Lower threshold to 50%, retry
│  │     └─ NO → Continue
│  │
│  └─ Calculate weights for each vote
│     │
│     └─ For each vote:
│        │
│        ├─ Load Thompson Sampling state
│        │  └─ Get historical_accuracy from bandit-state.json
│        │
│        ├─ Get tier_weight from MODEL_TIER_WEIGHTS
│        │  └─ opus=1.0, sonnet=0.85, haiku=0.6, etc.
│        │
│        ├─ Get capability_score from CAPABILITY_MATRIX
│        │  └─ taskType-specific (deepseek-coder=1.0 for code_generation)
│        │
│        ├─ Normalize confidence to 0.0-1.0
│        │  └─ Handle 0-100 scale, null, invalid
│        │
│        └─ Calculate weight
│           └─ weight = tier_weight × capability_score × confidence × historical_accuracy
│
├─ GROUP BY ANSWER
│  │
│  └─ For each unique answer:
│     │
│     ├─ Sum weights → total_weight
│     ├─ Count votes → vote_count
│     └─ Find max individual weight → max_individual_weight
│
├─ SORT GROUPS
│  │
│  ├─ Primary: total_weight (descending)
│  ├─ Tie-breaker 1: vote_count (descending)
│  ├─ Tie-breaker 2: max_individual_weight (descending)
│  └─ Tie-breaker 3: alphabetical (reproducibility)
│
├─ CALCULATE CONSENSUS
│  │
│  ├─ winner = groups[0]
│  ├─ runner_up = groups[1] || null
│  │
│  ├─ consensus_strength = winner.total_weight / sum(all_weights)
│  │
│  └─ consensus_level =
│     ├─ ≥80% → "strong"
│     ├─ ≥60% → "moderate"
│     ├─ ≥40% → "weak"
│     └─ <40% → "no_consensus"
│
├─ EDGE CASE DETECTION
│  │
│  ├─ TIE CHECK
│  │  │
│  │  └─ runner_up exists AND weight_difference < 1% of winner_weight?
│  │     └─ YES → EDGE CASE: "tie"
│  │     │         └─ Action: Flag for arbiter review
│  │     │         └─ Add tie_detected=true, recommendation="REQUIRE_ARBITER_REVIEW"
│  │     └─ NO → Continue
│  │
│  └─ CAPABILITY CHECK
│     │
│     └─ max(capability_scores) < 0.3?
│        └─ YES → EDGE CASE: "no_capable_models"
│        │         └─ Action: Fallback to 'general' task type, retry
│        └─ NO → Continue
│
└─ OUTPUT
   │
   ├─ voting_result
   │  ├─ status: "success"
   │  ├─ algorithm: "weighted_voting"
   │  ├─ task_type: taskType
   │  ├─ winner
   │  │  ├─ answer
   │  │  ├─ total_weight
   │  │  ├─ vote_count
   │  │  ├─ consensus_strength
   │  │  ├─ consensus_level
   │  │  └─ votes[] (model, weight, confidence breakdown)
   │  ├─ runner_up (if exists)
   │  │  ├─ answer
   │  │  ├─ total_weight
   │  │  ├─ vote_count
   │  │  └─ weight_difference
   │  ├─ all_groups[] (all answers with weights)
   │  └─ metadata
   │     ├─ total_votes
   │     ├─ filtered_votes
   │     ├─ discarded_votes
   │     ├─ min_confidence_threshold
   │     └─ num_unique_answers
   │
   ├─ edge_case
   │  ├─ type: "unanimous" | "tie" | "all_below_threshold" | "no_capable_models" | null
   │  └─ action: "fast_path" | "require_arbiter_review" | "lower_threshold" | "fallback_general"
   │
   ├─ buildArbiterPrompt(originalTask)
   │  └─ Generates prompt with:
   │     ├─ Winner answer + weight breakdown
   │     ├─ Individual vote weights (tier, capability, confidence, history)
   │     ├─ Runner-up (if exists)
   │     ├─ Edge case warnings (tie, low confidence, etc.)
   │     └─ Recommendation (approve winner, review carefully, etc.)
   │
   └─ summary
      ├─ winner_answer
      ├─ consensus_level
      ├─ total_weight
      └─ vote_count


================================================================================
WEIGHT CALCULATION DETAIL
================================================================================

INPUT: vote = { model, answer, confidence }
│
├─ Get tier_weight
│  │
│  └─ MODEL_TIER_WEIGHTS lookup
│     ├─ opus → 1.0
│     ├─ sonnet → 0.85
│     ├─ haiku → 0.6
│     ├─ fable → 0.95
│     ├─ gpt-4o → 0.95
│     ├─ gemini → 0.90
│     ├─ deepseek-coder → 0.70
│     ├─ phi-4-mini → 0.50
│     └─ unknown → 0.60 (default)
│
├─ Get capability_score
│  │
│  └─ CAPABILITY_MATRIX[taskType][model]
│     │
│     ├─ code_generation:
│     │  ├─ deepseek-coder → 1.0 (specialized)
│     │  ├─ opus → 0.95
│     │  ├─ sonnet → 0.90
│     │  └─ haiku → 0.70
│     │
│     ├─ code_review:
│     │  ├─ opus → 0.95
│     │  ├─ sonnet → 0.92
│     │  └─ haiku → 0.75
│     │
│     ├─ security_audit:
│     │  ├─ opus → 0.95
│     │  ├─ sonnet → 0.90
│     │  └─ haiku → 0.65
│     │
│     ├─ routing:
│     │  ├─ phi-4-mini → 1.0 (specialized)
│     │  ├─ fable → 0.82
│     │  └─ opus → 0.80
│     │
│     └─ general (fallback):
│        ├─ opus → 0.90
│        ├─ sonnet → 0.85
│        └─ haiku → 0.70
│
├─ Normalize confidence
│  │
│  ├─ confidence in 0-1 range? → use as-is
│  ├─ confidence in 0-100 range? → divide by 100
│  ├─ confidence is null/undefined/NaN? → default to 0.5
│  └─ confidence out of range? → default to 0.5
│
├─ Get historical_accuracy
│  │
│  └─ Load ~/.claude/learning/bandit-state.json
│     │
│     ├─ models[model].avg_quality exists?
│     │  └─ YES → use avg_quality (0.0-1.0)
│     │  └─ NO → default to 0.5 (neutral)
│     │
│     └─ Example values:
│        ├─ sonnet → 0.885 (88.5% historical accuracy)
│        ├─ opus → 0.556 (55.6%)
│        └─ haiku → 0.500 (50.0%)
│
└─ Calculate final weight
   │
   └─ weight = tier_weight × capability_score × confidence × historical_accuracy
      │
      └─ Clamp to [0.0, 1.0]


================================================================================
EXAMPLE: 30 haiku vs 5 opus
================================================================================

HAIKU (30 votes, answer="A", confidence=50%)
│
├─ tier_weight = 0.6
├─ capability_score = 0.75 (code_review)
├─ confidence = 0.5 (50%)
├─ historical_accuracy = 0.50 (from bandit-state.json)
│
├─ weight = 0.6 × 0.75 × 0.5 × 0.50 = 0.1125
│
└─ total_weight = 30 × 0.1125 = 3.375


OPUS (5 votes, answer="B", confidence=90%)
│
├─ tier_weight = 1.0
├─ capability_score = 0.95 (code_review)
├─ confidence = 0.9 (90%)
├─ historical_accuracy = 0.56 (from bandit-state.json)
│
├─ weight = 1.0 × 0.95 × 0.9 × 0.56 = 0.4788
│
└─ total_weight = 5 × 0.4788 = 2.394


RESULT:
├─ Winner: A (haiku)
├─ Total weight: 3.375 vs 2.394
├─ Consensus level: weak (58.7%)
│
└─ ANALYSIS: Volume overcame quality
   │
   └─ Solutions:
      ├─ Increase tier weight spread (haiku=0.4 instead of 0.6)
      ├─ Add non-linear confidence penalty
      └─ Add vote count penalty


================================================================================
EDGE CASE: TIE
================================================================================

INPUT: 2 opus vote "A" (85%), 2 opus vote "B" (84%)
│
├─ Calculate weights
│  ├─ A: 2 × 0.475 = 0.95
│  └─ B: 2 × 0.470 = 0.94
│
├─ Weight difference: 0.01
├─ Winner total weight: 0.95
├─ Margin: 0.01 / 0.95 = 1.05%
│
├─ TIE CHECK: margin < 1%?
│  └─ YES (1.05% ≈ 1%) → EDGE CASE: "tie"
│
├─ Action: Flag for arbiter review
│  ├─ tie_detected = true
│  ├─ tie_margin = "1.05%"
│  └─ recommendation = "REQUIRE_ARBITER_REVIEW"
│
└─ Arbiter receives:
   └─ "⚠️ TIE DETECTED: Top 2 answers within 1.05% weight difference.
       Requires careful arbiter review."


================================================================================
EDGE CASE: ALL VOTES BELOW THRESHOLD
================================================================================

INPUT: 3 votes with confidence 15%, 10%, 5% (threshold=20%)
│
├─ Filter by threshold
│  └─ filtered.length = 0 (all below 20%)
│
├─ EDGE CASE: "all_votes_below_threshold"
│
├─ Action: Lower threshold and retry
│  ├─ new_threshold = 20% × 0.5 = 10%
│  └─ Retry with new_threshold
│
├─ Retry filter
│  └─ filtered.length = 2 (15%, 10% pass)
│
├─ Run weighted voting
│  └─ Winner: highest weight among 2 votes
│
└─ Add warning to result:
   └─ "All votes below 20% threshold. Lowered to 10% and retried."


================================================================================
EDGE CASE: UNANIMOUS
================================================================================

INPUT: 4 votes, all answer="A"
│
├─ Detect: unique answers = 1
│
├─ EDGE CASE: "unanimous"
│
├─ Action: Fast-path (skip weighted calculation)
│  │
│  └─ Calculate average weight
│     ├─ weights = [0.475, 0.588, 0.135, 0.420]
│     └─ avg = 0.4045
│
└─ Return:
   ├─ algorithm: "unanimous_vote"
   ├─ consensus_level: "unanimous"
   ├─ consensus_strength: 1.0
   └─ total_weight: avg × vote_count = 1.618


================================================================================
POSTGRESQL AUDIT TRAIL
================================================================================

After voting completes:
│
└─ storeAuditTrail(votingResult, workflowExecutionId)
   │
   ├─ Create table workflow.weighted_votes (if not exists)
   │
   └─ INSERT INTO workflow.weighted_votes
      ├─ workflow_execution_id
      ├─ task_type
      ├─ winning_answer (JSONB)
      ├─ total_weight
      ├─ consensus_level
      ├─ consensus_strength
      ├─ vote_count
      ├─ vote_details (JSONB) - full breakdown
      ├─ edge_case
      ├─ edge_case_action
      └─ created_at (timestamp)


Query examples:
│
├─ Recent votes:
│  └─ SELECT * FROM workflow.weighted_votes
│     ORDER BY created_at DESC LIMIT 20;
│
├─ Weak consensus (needs attention):
│  └─ SELECT * FROM workflow.weighted_votes
│     WHERE consensus_level IN ('weak', 'no_consensus')
│     ORDER BY created_at DESC;
│
├─ Ties detected:
│  └─ SELECT * FROM workflow.weighted_votes
│     WHERE edge_case = 'tie'
│     ORDER BY created_at DESC;
│
└─ Edge case frequency:
   └─ SELECT edge_case, COUNT(*)
      FROM workflow.weighted_votes
      WHERE created_at > NOW() - INTERVAL '7 days'
      GROUP BY edge_case;


================================================================================
ARBITER INTEGRATION
================================================================================

After weighted voting:
│
├─ Generate arbiter prompt
│  │
│  └─ arbiterPrompt = votingResult.buildArbiterPrompt(originalTask)
│     │
│     └─ Prompt includes:
│        ├─ [WEIGHTED VOTING RESULTS]
│        ├─ Original task
│        ├─ WINNER (consensus level)
│        │  ├─ Answer
│        │  ├─ Total weight
│        │  ├─ Vote count
│        │  ├─ Consensus strength
│        │  └─ Supporting votes (model, weight breakdown)
│        ├─ RUNNER-UP (if exists)
│        │  ├─ Answer
│        │  ├─ Total weight
│        │  └─ Weight difference
│        ├─ METADATA
│        │  ├─ Total votes
│        │  ├─ Discarded (low confidence)
│        │  └─ Unique answers
│        ├─ ⚠️ EDGE CASE warnings (if any)
│        └─ YOUR TASK
│           └─ Review, validate, decide (approve/select runner-up/synthesize)
│
├─ Send to arbiter
│  │
│  └─ arbiterDecision = await agent(arbiterPrompt, {
│        model: 'opus',
│        schema: arbiterSchema,
│     })
│
└─ Arbiter has full context:
   ├─ Individual vote weights (transparency)
   ├─ Edge case warnings (tie, low confidence)
   ├─ Consensus strength (strong/moderate/weak)
   └─ Recommendation (approve or review carefully)
