Claude Integration with Atlassian (Jira + Confluence)

Last Updated: 2026-06-16
Author: Scot Floess
Purpose: Enable Claude Code to access Jira and Confluence for automated workflows

Overview

This guide walks through setting up API token authentication for Claude Code to access:

  • Jira - Create, update, and query issues/tickets
  • Confluence - Create, update, and read wiki pages

Use Cases:

  • Automated release notes publishing (R305, R309)
  • Jira ticket updates with fix versions
  • Documentation generation and updates
  • Integration with CI/CD workflows

Prerequisites

  • Atlassian account with Jira and Confluence access
  • Python 3.8+ installed
  • Command line access to your development machine

Step 1: Create Atlassian API Token

  1. Go to Atlassian Account Security
  2. Click "Create API token"
  3. Label: "Claude Code Integration"
  4. Click "Create"
  5. ⚠️ IMPORTANT: Copy the token immediately! You cannot view it again

Note: The same API token works for both Jira and Confluence since they're both Atlassian products under the same account.

Troubleshooting

Common Issues

Error: 401 Unauthorized

  • Check that your API token is correct
  • Verify your email matches your Atlassian account
  • Token may have been revoked - create a new one

Error: 403 Forbidden

  • You don't have permissions for the requested operation
  • Contact your Jira/Confluence administrator

Error: 404 Not Found

  • Check the URL - make sure it's redhat.atlassian.net
  • For Confluence, include /wiki in the URL
  • Verify the page/issue ID exists

Security Notes

  • Never commit API tokens to git!
  • Store tokens in environment variables or secrets management
  • API tokens have the same permissions as your user account
  • Regularly rotate your API tokens (every 90 days recommended)
  • Revoke tokens immediately if compromised
