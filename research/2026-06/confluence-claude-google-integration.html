Claude Integration with Google (Gmail + Drive)

Last Updated: 2026-06-16
Author: Scot Floess
Purpose: Enable Claude Code to access Gmail and Google Drive for automated workflows

Overview

This guide walks through setting up OAuth 2.0 authentication for Claude Code to access:

  • Gmail API - Send and read emails programmatically
  • Google Drive API - Read and write documents

Use Cases:

  • Automated release note emails (R305, R309)
  • Document generation and storage
  • Email-based notifications and reports

Prerequisites

  • Google account with admin access
  • Python 3.8+ installed
  • Command line access to your development machine

Step 1: Create Google Cloud Project

  1. Go to Google Cloud Console
  2. Click "Select a project" → "New Project"
  3. Name: "Claude Integration" (or your preference)
  4. Click "Create"

Step 2: Enable Required APIs

  1. Go to APIs & Services → Library
  2. Enable Gmail API:
    • Search for "Gmail API"
    • Click "Enable"
  3. Enable Google Drive API:
    • Search for "Google Drive API"
    • Click "Enable"

Step 3: Configure OAuth Consent Screen

  1. Go to APIs & Services → Credentials
  2. Click "OAuth consent screen"
  3. User Type: "External" (or "Internal" if Google Workspace)
  4. Fill in required fields:
    • App name: "Claude Code Integration"
    • User support email: (your email)
    • Developer contact: (your email)
  5. Add Scopes:
    • https://www.googleapis.com/auth/gmail.send
    • https://www.googleapis.com/auth/gmail.readonly
    • https://www.googleapis.com/auth/drive.readonly
    • https://www.googleapis.com/auth/drive.file
  6. Add your email as a test user
  7. Click "Save and Continue"

Step 4: Create OAuth Credentials

  1. Go to "Credentials" tab
  2. Click "+ Create Credentials" → "OAuth client ID"
  3. Application type: "Desktop app"
  4. Name: "Claude Code Desktop"
  5. Click "Create"
  6. Download the JSON file (credentials.json)

Troubleshooting

Common Issues

Error: "Access blocked: This app's request is invalid"

  • Make sure you added your email as a test user in OAuth consent screen
  • App must be in "Testing" mode for external users

Error: "Token has been expired or revoked"

  • Delete ~/.config/google-oauth/token.json
  • Run the OAuth flow again

Error: "credentials.json not found"

  • Make sure you downloaded the OAuth client credentials
  • Check the file path: ~/.config/google-oauth/credentials.json

Security Notes

  • Never commit credentials to git! Add .config/google-oauth/ to .gitignore
  • Refresh tokens do not expire unless revoked
  • Store environment variables securely (use secrets management in production)
  • Limit OAuth scopes to only what you need
