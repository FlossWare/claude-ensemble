# Doc Improve - Iterative Documentation Quality Improvement

Iteratively improve documentation quality with multi-AI consensus.

## Features

- **Iterative Loop** - Keeps improving until quality threshold met
- **Multi-Model Review** - Multiple AIs suggest improvements
- **Quality Tracking** - Measures quality score improvement
- **Automatic Enhancement** - Applies best improvements

## Usage

```bash
/doc-improve [PATH] [OPTIONS]
```

## Options

- `PATH` - Target directory or file (default: current directory)
- `--threshold=N` - Stop when quality score >= N (default: 90)
- `--max-iterations=N` - Maximum iterations (default: 10)
