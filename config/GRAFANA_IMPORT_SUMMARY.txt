DASHBOARD VARIABLES (FILTERS)
================================================================================

All variables are optional and filter all relevant panels:

node (Query: label_values(fleet_node_info, hostname))
  Values: laptop-01, aio-01, server-01, server-02, server-03, pi-02
  Multi-select: Yes (All by default)
  Affects: Most panels (CPU, memory, workflows, costs, etc.)

model (Query: label_values(ai_learning_execution_total, model))
  Values: claude-opus-4, claude-sonnet-4, claude-haiku-4, gpt-4o, gemini-2
  Multi-select: Yes (All by default)
  Affects: Cost breakdown, performance leaderboard, quality metrics

task_type (Query: label_values(ai_learning_execution_total, task_type))
  Values: code-review, test, solve, learn, debug, validate
  Multi-select: Yes (All by default)
  Affects: Task distribution, task breakdown, heatmaps

workflow (Query: label_values(ai_learning_execution_total, workflow))
  Values: ai-consensus, code-sdlc, ai-learning, etc.
  Multi-select: Yes (All by default)
  Affects: Workflow timeline, workload trends

PROMETHEUS METRICS REQUIRED
================================================================================

The dashboard queries these Prometheus metrics. Missing metrics will show
"No data" in corresponding panels.

Fleet Metrics (must-have for full functionality):
  fleet_node_info{hostname,role,ip,cpu_count,memory_gb}
  fleet_node_health{hostname}
  fleet_node_uptime_seconds{hostname}
  fleet_active_workflows{hostname}
  fleet_connection{source,dest,type}
  fleet_model_active{hostname,model,status}
  fleet_tasks_completed_total{hostname,task_type}
  fleet_workflow_state{run_id,workflow,hostname,status}
  fleet_nfs_latency_ms{}
  fleet_electricity_cost_estimate{hostname}
  fleet_nfs_bytes_total{source,dest}

Node Exporter Metrics (Linux system metrics):
  node_cpu_seconds_total{hostname,mode}
  node_memory_MemAvailable_bytes{hostname}
  node_memory_MemTotal_bytes{hostname}
  node_network_transmit_bytes_total{hostname}
  node_network_receive_bytes_total{hostname}
  node_nfs_read_bytes_total{hostname}
  node_nfs_write_bytes_total{hostname}

AI Learning Metrics:
  ai_learning_execution_total{model,hostname,task_type,workflow,status}
  ai_learning_cost_usd{model,hostname}
  ai_learning_quality_score{model}
  ai_learning_success_rate{model}
  ai_learning_duration_seconds{model}
  ai_learning_model_selection_rate{model}
  ai_learning_consensus_score{model}

Ollama Metrics:
  ollama_model_loaded{hostname,model}

NFS Metrics:
  nfs_request_duration_seconds_bucket{hostname,quantile}

Alerts Job:
  {job="fleet_alerts"} logs

TROUBLESHOOTING QUICK CHECKS
================================================================================

"No data" in panels?
  1. Check Prometheus is running:
     curl http://aio-01:9091/-/healthy

  2. Check metrics are being exported:
     curl http://aio-01:9091/metrics | grep fleet_

  3. Test Grafana datasource:
     Click gear icon (⚙️) → Data Sources → Prometheus → Test

Cannot login?
  Default credentials: admin / admin

Variables dropdowns are empty?
  Check if Prometheus has the labels:
  curl 'http://aio-01:9091/api/v1/label/hostname/values'

Dashboard looks blank?
  1. Check time range (top right) - adjust from "Last 7 days" if needed
  2. Check variables at top - all should say "All"
  3. Check Prometheus has scraped metrics from all targets:
     http://aio-01:9091/targets

NEXT STEPS AFTER INSTALLATION
================================================================================

1. VERIFY METRICS ARE FLOWING
   - Open http://aio-01:9091/metrics
   - Search for "fleet_" to see if metrics are present
   - If empty, start metric exporters on each node

2. CHECK PROMETHEUS SCRAPE TARGETS
   - Visit http://aio-01:9091/targets
   - Verify all targets show green "UP" status
   - If any show red, check scrape configs

3. VIEW DASHBOARD
   - Open http://aio-01:3000/d/fleet-node-activity/
   - Panels should start showing data within 1-2 minutes
   - Verify all variables populate (node, model, task_type, workflow)

4. CUSTOMIZE IF NEEDED
   - Edit panels: Click panel → Edit
   - Change thresholds: Click panel → Edit → Field config
   - Add new panels: Click + icon
   - Modify variables: Gear icon (⚙️) → Variables

5. CONFIGURE ALERTING (OPTIONAL)
   - Click panel → Edit → Alert tab
   - Set threshold conditions
   - Choose notification channels (Slack, Email, PagerDuty)

6. SHARE WITH TEAM
   - Click share icon at top right
   - Generate public link or share via email
