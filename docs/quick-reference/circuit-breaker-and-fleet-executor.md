Fast reference for the two working features from Issues #268-273.

## Circuit Breaker Provider Extension

**File:** `shared/circuit-breaker-provider-extension.cjs`  
**Purpose:** Filter models by provider availability (removes entire provider's models during API outages)

### API

```javascript
const { filterAvailableModels } = require('./shared/circuit-breaker-provider-extension.cjs');

// Filter models by provider availability
const modelList = [
  'anthropic/opus',
  'anthropic/sonnet',
  'openai/gpt-4o',
  'openai/gpt-4o-mini'
];

const available = await filterAvailableModels(modelList);
// If Anthropic is down: ['openai/gpt-4o', 'openai/gpt-4o-mini']
```

### How It Works

1. Calls `getProviderAvailability()` from `monitoring/api-health-monitor.cjs`
2. Extracts provider from model name (e.g., "anthropic/opus" → "anthropic")
3. Filters out models from disabled providers
4. Returns filtered list

### Integration Point

Auto-generated by `monitoring/api-health-monitor.cjs` during API health checks.

## Fleet Executor (Python)

**File:** `shared/fleet_executor.py`  
**Purpose:** Distributed task execution via Python with zero dependencies

### Features

- ✅ **Zero dependencies** (stdlib only)
- ✅ **Cross-platform** (x86_64, arm64, armhf)
- ✅ **Python 3.8+** compatible
- ✅ **Auto-retry** with exponential backoff
- ✅ **10 providers** supported
- ✅ **SSH-safe** (hostname validation)

### Single Worker API

```python
from fleet_executor import execute_on_worker

result = execute_on_worker(
    worker='server-01',          # Hostname (validates for SSH safety)
    model='gpt-4o-mini',         # Model name
    task='Analyze this code',    # Task/prompt
    max_tokens=4096,             # Max response tokens
    timeout_ms=30000,            # Timeout (milliseconds)
    max_retries=2,               # Retries on 429/500/502/503/504
    backoff_seconds=1.0          # Initial backoff (doubles each retry)
)

# Result:
# {
#   'output': 'Model response...',
#   'duration_ms': 2345,
#   'execution_host': 'server-01',
#   'provider': 'openai',
#   'input_tokens': 150,
#   'output_tokens': 800,
#   'ssh_overhead_ms': 45
# }
```

### Parallel Fleet API

```python
from fleet_executor import execute_on_fleet_parallel

results = execute_on_fleet_parallel(
    workers=['server-01', 'server-02', 'server-03'],
    model='gpt-4o-mini',
    tasks=['Task 1', 'Task 2', 'Task 3'],  # One per worker
    max_tokens=4096,
    timeout_ms=30000,
    max_retries=2,
    backoff_seconds=1.0
)

# Results: list of 3 result dicts (same format as single worker)
```

### Error Handling

**Transient Errors (auto-retry):**
- 429: Rate limit
- 500: Server error
- 502: Bad gateway
- 503: Service unavailable
- 504: Gateway timeout

**Retry Behavior:**
- Attempt 1: Immediate
- Attempt 2: Wait 1s
- Attempt 3: Wait 2s
- Attempt 4: Wait 4s (if max_retries=3)

**Non-Retryable Errors:**
- 400: Bad request (fix your input)
- 401: Unauthorized (check API key)
- 403: Forbidden (check permissions)
- 404: Not found (check model name)

### Local vs Remote Execution

**Local (worker='aio-01' or 'localhost'):**
```python
result = execute_on_worker(
    worker='aio-01',
    model='gpt-4o-mini',
    task='...'
)
# Runs locally via subprocess (no SSH)
```

**Remote (any other hostname):**
```python
result = execute_on_worker(
    worker='server-01',
    model='gpt-4o-mini',
    task='...'
)
# Runs via SSH: ssh claude@server-01 python3 /opt/claude-orchestrator/shared/python-worker.py
```

### SSH Safety

**Hostname validation prevents command injection:**

```python
# Valid hostnames
execute_on_worker(worker='server-01', ...)      # ✅
execute_on_worker(worker='aio-01.local', ...)   # ✅
execute_on_worker(worker='192.168.1.100', ...)  # ✅ (IP addresses allowed)

# Invalid hostnames (raises ValueError)
execute_on_worker(worker='server-01; rm -rf /', ...)  # ❌ Semicolon
execute_on_worker(worker='server-01 && evil', ...)    # ❌ Shell operators
execute_on_worker(worker='server-01 | nc', ...)       # ❌ Pipe
```

**Regex validation:**
- Alphanumeric, dots, hyphens only
- No leading/trailing dot/hyphen
- Max 253 chars total
- Each label 1-63 chars
- RFC 952 / RFC 1123 compliant

### Example: Multi-Provider Parallel Execution

```python
from fleet_executor import execute_on_worker
import concurrent.futures

providers = [
    ('server-01', 'gpt-4o-mini'),        # OpenAI
    ('server-02', 'claude-3-5-haiku'),   # Anthropic
    ('server-03', 'gemini-3.5-flash'),   # Google
    ('laptop-01', 'llama-3.3-70b'),      # Groq
    ('pi-01', 'nvidia/nemotron-3-super-120b-a12b:free')  # OpenRouter
]

task = "What is the capital of France?"

def run_worker(worker, model):
    return execute_on_worker(
        worker=worker,
        model=model,
        task=task,
        max_retries=2
    )

# Run all 5 providers in parallel
with concurrent.futures.ThreadPoolExecutor(max_workers=5) as executor:
    futures = [executor.submit(run_worker, w, m) for w, m in providers]
    results = [f.result() for f in concurrent.futures.as_completed(futures)]

# Analyze results
for result in results:
    if 'error' not in result:
        print(f"{result['execution_host']}: {result['output'][:100]}")
        print(f"  Duration: {result['duration_ms']}ms")
        print(f"  Provider: {result['provider']}")
```
