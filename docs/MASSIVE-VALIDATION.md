## Validation Strategies

### Strategy 1: Random Sample Consensus (Fast)
**Use case:** Quick validation  
**Method:** Randomly select N models from 252, get majority vote  
**Sample size:** 20-30 models  
**Time:** ~2 minutes  
**Cost:** $0 (all free)

**Example:**
```javascript
// Validate fine-tuned deepseek-coder on Java task
const validators = randomSample(allFreeModels, 25)
const results = await parallel(validators.map(model => () => 
  agent(`Review this Java code generated by deepseek-coder-java:

${generatedCode}

Rate quality 1-10 and explain why.`, {
    model: model,
    schema: { type: 'object', properties: {
      quality: { type: 'number' },
      reasoning: { type: 'string' }
    }}
  })
))

const avgQuality = results.filter(Boolean).map(r => r.quality).reduce((a,b) => a+b, 0) / results.length
const consensus = avgQuality > 7 ? 'GOOD' : 'NEEDS_WORK'
```

### Strategy 3: Full Democratic Vote (Exhaustive)
**Use case:** Critical decisions, final validation  
**Method:** Ask ALL 252 models  
**Sample size:** 252 models  
**Time:** ~15-20 minutes (parallel batches)  
**Cost:** $0

**Batching:**
```javascript
// Process in batches of 50 (avoid overwhelming servers)
const batchSize = 50
const allResults = []

for (let i = 0; i < allFreeModels.length; i += batchSize) {
```

### Strategy 4: Specialist Committees (Smart)
**Use case:** Task-specific validation  
**Method:** Use models profiled as strong for this task type  
**Sample size:** Variable (depends on task type)  
**Time:** ~1-2 minutes  
**Cost:** $0

**Example:**
```javascript
// For Java code validation, use models good at code_generation + code_review
const codeSpecialists = await db.query(`
  SELECT model_id 
  FROM learning.model_capabilities
  WHERE (code_generation > 0.7 OR code_review > 0.7)
  ORDER BY (code_generation + code_review) DESC
  LIMIT 30
`)

// Only use specialists, not random models
const validation = await parallel(codeSpecialists.map(m => () =>
  agent(validateCodePrompt, { model: m.model_id })
))
```

### Strategy 5: Adversarial Multi-Round (Rigorous)
**Use case:** Find edge cases, stress test  
**Method:** Round 1 validates, Round 2 tries to refute Round 1  
**Rounds:** 2-3  
**Sample size:** 50-100 models total  
**Time:** ~5-10 minutes  
**Cost:** $0

**Example:**
```javascript
// Round 1: 25 models validate
const round1 = await parallel(randomSample(allModels, 25).map(m => () =>
  agent(`Rate this code quality 1-10`, { model: m })
))

const round1Avg = average(round1)

// Round 2: 25 DIFFERENT models try to refute
const round2 = await parallel(randomSample(allModels, 25).map(m => () =>
  agent(`Previous validators rated this ${round1Avg}/10. 
         Try to REFUTE their assessment. 
         Find problems they missed.`, { model: m })
))

// If round2 finds major issues, trigger round3
const criticalIssues = round2.filter(r => r.severity === 'critical')
if (criticalIssues.length > 5) {
  // More scrutiny needed
}
```

## Validation Workflow for Fine-Tuned Models

**Use case:** Validate deepseek-coder-java after fine-tuning

```javascript
export const meta = {
  name: 'validate-finetuned-massive',
  description: 'Validate fine-tuned models with 252 FREE model consensus',
  phases: [
    { title: 'Test Base Model', detail: '35 validators test original model' },
    { title: 'Test Fine-Tuned', detail: '35 validators test fine-tuned model' },
    { title: 'Compare', detail: 'Statistical analysis of improvement' },
    { title: 'Adversarial', detail: '25 models try to break it' }
  ]
}

// Phase 1: Test base deepseek-coder
const baseResults = await providerDiverseValidation({
  prompt: `Generate a Java Salesforce Apex trigger for Contact updates...`,
  model: 'deepseek-ai/deepseek-coder-6.7b-instruct',  // Base model
  validators: 35
})

// Phase 2: Test fine-tuned deepseek-coder-java
const fineResults = await providerDiverseValidation({
  prompt: `Generate a Java Salesforce Apex trigger for Contact updates...`,
  model: 'deepseek-coder-java:finetuned',  // Fine-tuned
  validators: 35
})

// Phase 3: Statistical comparison
const improvement = {
  avgQualityBase: average(baseResults.map(r => r.quality)),
  avgQualityFine: average(fineResults.map(r => r.quality)),
  improvementPct: ((avgQualityFine - avgQualityBase) / avgQualityBase * 100),
  tTestSignificance: tTest(baseResults, fineResults),  // p < 0.05?
  consensusImproved: fineResults.filter(r => r.quality > 7).length > baseResults.filter(r => r.quality > 7).length
}

// Phase 4: Adversarial testing (try to break it)
const adversarial = await parallel(randomSample(allModels, 25).map(m => () =>
  agent(`This code was generated by fine-tuned model.
         Find bugs, edge cases, security issues.
         Try to make it fail.
         
         Code: ${fineResults[0].generatedCode}`, { model: m })
))

const criticalBugs = adversarial.filter(Boolean).filter(r => r.severity === 'critical')

return {
  base_quality: improvement.avgQualityBase,
  finetuned_quality: improvement.avgQualityFine,
  improvement_pct: improvement.improvementPct,
  statistical_significance: improvement.tTestSignificance < 0.05,
  critical_bugs_found: criticalBugs.length,
  recommendation: criticalBugs.length === 0 && improvement.improvementPct > 20 
    ? 'DEPLOY' 
    : 'NEEDS_WORK'
}
```

## Implementation

**Create:** `tools/massive_validator.py`

```python
import random
from collections import Counter

class MassiveValidator:
    def __init__(self, db):
        self.db = db
        self.all_models = self.load_all_models()
    
    def provider_diverse_sample(self, n_per_provider=5):
        """Select top N from each provider"""
        providers = ['mistral', 'deepinfra', 'huggingface', 
                     'google-gemini', 'openrouter', 'groq', 'cerebras']
        
        selected = []
        for provider in providers:
            provider_models = [m for m in self.all_models if m['provider'] == provider]
            # Prefer profiled models with high scores
            sorted_models = sorted(provider_models, 
                                 key=lambda m: m.get('avg_capability', 0), 
                                 reverse=True)
            selected.extend(sorted_models[:n_per_provider])
        
        return selected
    
    def full_democratic_vote(self):
        """All 252 models vote"""
        return self.all_models
    
    def specialist_committee(self, task_type='code_generation', min_score=0.7, limit=30):
        """Models good at specific task type"""
        cursor = self.db.cursor()
        cursor.execute(f"""
            SELECT model_id, {task_type}
            FROM learning.model_capabilities
            WHERE {task_type} > %s
            ORDER BY {task_type} DESC
            LIMIT %s
        """, (min_score, limit))
        
        return [{'model_id': row[0], 'score': row[1]} for row in cursor.fetchall()]
```
