CORE API (3 Functions)
================================================================================

postMessage(channel, message)
  - Post a message to a channel
  - Auto-enriches with id, timestamp, channel
  - Returns enriched message object
  - Example: bus.postMessage('findings', {text: 'Issue found'})

readMessages(channel, since?)
  - Read all messages from a channel
  - Optional time filtering by ISO timestamp
  - Returns array of messages (oldest first)
  - Example: bus.readMessages('general', new Date(Date.now() - 3600000))

listChannels()
  - List all available channels
  - Returns array of channel names
  - Example: const channels = bus.listChannels()

================================================================================
EXTENDED API (4 Functions)
================================================================================

getChannelStats(channel)
  - Get message count and timestamp range
  - Returns: {channel, messageCount, oldestMessage, newestMessage}
  - Example: const stats = bus.getChannelStats('findings')

searchMessages(channel, query, field?)
  - Full-text search within channel
  - Supports string or regex queries
  - Optional field-specific search
  - Example: bus.searchMessages('findings', 'critical')

deleteMessage(channel, messageId)
  - Delete a specific message by ID
  - Returns true if found and deleted
  - Example: bus.deleteMessage('general', msg.id)

clearChannel(channel)
  - Delete all messages from a channel
  - Returns true always
  - Example: bus.clearChannel('experiments')

================================================================================
STORAGE FORMAT
================================================================================

Location: ~/.claude/learning/messages/
Format: JSONL (JSON Lines - one object per line)
File Pattern: {channel-name}.jsonl

Example Message:
  {
    "id": "msg_1781364679974_v8w6z7gos",
    "timestamp": "2026-06-13T15:31:19.974Z",
    "channel": "general",
    "text": "Hello world",
    "author": "claude",
    "priority": "normal"
  }

Message Fields:
  - id: Auto-generated unique identifier
  - timestamp: ISO 8601 timestamp (auto-generated)
  - channel: Channel name (auto-added)
  - *: All custom fields from message parameter

Channel Naming:
  - Alphanumeric, dash, underscore allowed
  - Special characters replaced with underscores
  - Example: 'my:channel@2024!' → 'my_channel_2024_'

PERFORMANCE CHARACTERISTICS

Complexity Analysis:

Characteristics:

  - Local only: Single machine deployment
  - Durable: Persisted to disk immediately
