# Only Free Services for Personal Projects

Personal projects use ONLY truly free models/APIs — no paid, no "cheap", no credits, no trials.

**Why:** Zero cost for personal work. If it costs anything, it's not an option. Paid services are Red Hat only (covered by employer).

**How to apply:**
- **FREE means $0.00** — not "cheap", not "affordable", not "credits needed", not "trial period"
- Never suggest paid personal API keys, subscriptions, credit-based services, or trial tiers
- When recommending providers, ONLY include those with genuinely free tiers (no credit card, no balance)
- Exclude from personal use: OpenAI (needs credits), DeepSeek (paid), DeepInfra embeddings (paid), MiniMax (paid), Qwen Cloud (trial only)
- **Confirmed free providers:** Groq, Cerebras, OpenRouter (free-tagged models only), Mistral (free tier), Gemini (free tier), Cloudflare Workers AI, HuggingFace, Cohere (free tier), Jina (free tier)
- Paid Red Hat tools (Cursor Enterprise, Claude Code Vertex, Gemini API) are covered by employer
