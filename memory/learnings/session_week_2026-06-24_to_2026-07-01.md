## 3. Critical Feedback Patterns (Reinforced)

### ALWAYS Hybrid Multi-AI ✅

**Rule:** ALWAYS use hybrid (3 Anthropic + 3 local) for multi-AI consensus

**Empirical Evidence:**
- harness_cli review: Hybrid found 25% MORE bugs than Anthropic-only
- Local models caught infinite loop risk Opus/Sonnet/Haiku missed
- Model diversity = different architectures catch different bug classes

**Pattern:**
```javascript
// Verifiers: 6-vote hybrid
parallel([
  () => agent(prompt, { model: 'opus' }),     // Anthropic
  () => agent(prompt, { model: 'sonnet' }),   // Anthropic  
  () => agent(prompt, { model: 'haiku' }),    // Anthropic
  () => agent(prompt, { agentType: 'general-purpose' }), // Local 1
  () => agent(prompt, { agentType: 'general-purpose' }), // Local 2
  () => agent(prompt, { agentType: 'general-purpose' })  // Local 3
])
```

**Why it matters:**
- Red Hat compliant (local models approved)
- Cost efficient (50% free vs 100% paid)
- Quality: Hybrid FREE+PAID = 95-98% (best ROI)

### Loop Until Perfect ✅

**Rule:** No arbitrary cycle limits on review loops

**User directive (2026-06-15):** "I want loop until perfect"

**Correct pattern:**
```javascript
// ✅ CORRECT - loop until perfect
while (!allPassed) {
  reviewCycle++
  if (reviewCycle % 5 === 0) {
    log(`${reviewCycle} review cycles - continuing...`)
  }
  // review and fix - KEEP GOING
}
```

**Natural stop conditions (acceptable):**
- ✅ Adversarial review passes
- ✅ Token budget exhausted (user-set)
- ✅ System timeout (10-min workflow max)
- ✅ User interrupt

**Artificial limits (NEVER):**
- ❌ Max review cycles (3, 5, 10)
- ❌ "Best effort after N tries"

## 6. Terminology Correction (Important)

**Rule:** Never use "deep learning" terminology for multi-AI analysis workflows

**Why:** "Deep learning" means neural networks with gradient descent/backpropagation. Using it for research/analysis is misleading and contradicts core principle: this is orchestration over pre-trained models, NOT a learning system.

**Correct terminology:**
- ✅ System audit
- ✅ Deep research  
- ✅ Multi-AI analysis
- ✅ Self-introspection
- ✅ Comprehensive review

**Incorrect terminology:**
- ❌ Deep learning (implies neural network training)
- ❌ Self-learning (implies autonomous model improvement)
- ❌ Learning workflow (implies fine-tuning)
- ❌ Training pipeline (implies gradient descent)

**Context:** CLAUDE.md explicitly states:
```
What This System IS NOT:
- ✗ Learning system (no model training, no weight updates)
- ✗ Self-improving AI (same model capabilities throughout)
```

All improvements are from routing efficiency, task decomposition, retry logic - NOT model intelligence gains.
