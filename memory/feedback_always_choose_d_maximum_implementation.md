## Exceptions (Rare!)

**Only present options when:**
1. **Fundamentally different approaches** (not just scope)
   - "Use IIT theory vs GWT theory?" (mutually exclusive)
   - "Python implementation vs Node.js?" (architectural choice)

2. **Cost/risk tradeoffs** that user MUST decide
   - "Delete production data? (destructive, needs confirmation)"
   - "Spend $1000 on API calls? (cost approval needed)"

3. **Mutually exclusive technical choices**
   - "Use Postgres vs MongoDB?" (can't do both)
   - "Deploy to AWS vs GCP?" (location choice)

**But even then:** Recommend the MAXIMUM CAPABILITY option and explain why!
