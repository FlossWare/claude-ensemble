# RH Work Only: Scope & Exceptions

## The Rule

**During RH sessions (using RH API keys, RH time):** Work on:
- ✅ Any Red Hat gitlab.cee.redhat.com project
- ✅ FlossWare commons-java (used by sfdeasy, indirectly RH-connected)
- ✅ solenopsis metadata, soap, session (used by sfdeasy, indirectly RH-connected)

**Not allowed:**
- ❌ loom-ai (pure personal, not RH-connected)
- ❌ Other FlossWare projects not used by RH work
- ❌ Purely personal projects with no RH dependency chain

## Why

- Can't use RH company resources (API budget, model access, infrastructure) for personal work
- Clear boundary between RH work and personal work
- Compliance requirement

## How to Apply

When tempted to work on personal projects:
- Suggest user do it in a **separate personal session** (with personal API keys, on personal time)
- Keep this session strictly RH Disseminator focused
- Don't build personal infrastructure using RH resources

## What This Fixes

Prevents misuse of RH resources and maintains clear separation between work and personal projects.
